# Demo Capture Guide

Place final README demo screenshots in this folder before submission.

Recommended files:

- `01_qr_setup.png`: QR connection and setup screen.
- `02_board_registration.png`: gate marker detection and OK-sign registration progress.
- `03_combat.png`: AR board, enemy model, player cards, and combat UI.
- `04_reward_select.png`: reward cards after wave clear.
- `05_defeat_restart.png`: defeat overlay and OK-sign restart progress.
- `06_chrome_flags_insecure_origin.png`: Chrome flags page showing `Insecure origins treated as secure`.

Use real runtime screenshots only. Do not use mock images for the final submission.

Gameplay demo video should be uploaded externally, then linked from the main README. Recommended length: 30-60 seconds.
